3. CONCLUSION

Both Merge Sort and Quick Sort correctly sorted the
given IDs.

Merge Sort provides guaranteed O(n log n) worst-case
time complexity, while Quick Sort has O(n log n)
average-case complexity but can reach O(n^2) in the
worst case.

Merge Sort requires O(n) additional memory, whereas
Quick Sort generally requires less additional memory.

For large datasets where predictable worst-case
performance is important, Merge Sort is a suitable
choice.
